# Dhaka Emergency Finder

> **Emergency in Bangladesh? Call 999 first.**

Find the hospital, pharmacy, police or fire station in Dhaka that you can **reach fastest**, ranked by travel time
instead of straight-line distance. It works through an AI agent ([Geoapify MCP](https://apidocs.geoapify.com/mcp/))
or a small Python CLI written by an AI coding agent from the [Geoapify OpenAPI specifications](https://apidocs.geoapify.com/open-api/).
